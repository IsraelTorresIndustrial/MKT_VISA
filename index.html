Banco de Chile · Icon Decision Matrix

Sistema de decisión para selección de iconografía en campañas de medios de pago

💾 Descargar Documento .md
Pregunta Clave: "¿Qué concepto necesita entender el usuario en menos de 2 segundos?"
No seleccionar un ícono porque “se ve bonito”, sino porque representa el significado principal del bloque.

1. Regla de Prioridad Semántica

Cuando una comunicación contenga varios conceptos, elegir el icono según este orden estricto:

1️⃣ Acción Principal del Cliente
Si el bloque explica el beneficio principal o recompensa directa (ej. 24_descuento, 09_cashback).
2️⃣ Mecánica o Condición
Si la condición técnica es clave (ej. 25_cuotas_sin_interes, 08_meta_de_transacciones).
3️⃣ Rubro o Comercio
Si el bloque explica dónde usarlo (ej. 11_supermercado, 12_gastronomia, 14_combustible).
4️⃣ Medio de Pago
Si el foco es el producto o canal (ej. 01_tarjeta, 04_wallet, 21_contactless).

2. Familias de Íconos (Las 3 Categorías Oficiales)

  • Medios de Pago & Ciclo de Uso: Representan el medio de pago, el momento del journey (onboarding, activación, inactividad) o el comportamiento buscado.
  • Rubros de Consumo: Representan el contexto de gasto o categoría comercial (Supermercados, Cafeterías, Farmacias, Delivery, etc.).
  • Mecánicas, Crossborder & Travel: Representan una condición comercial, modalidad de uso o experiencia específica (Dólares-Premio, Cuotas, Salones VIP, Traslados).
