# Banco de Chile · 2D Icon Decision Matrix · Grupo 4
## Contextos Específicos, Innovación & Canales

**Versión:** 1.0  
**Biblioteca:** BCH · Medios de Pago · Iconografía 2D · Grupo 4  
**Cantidad:** 10 iconos PNG transparentes  
**Rango:** 31–40  
**Objetivo:** ampliar la biblioteca base de 30 iconos con una capa más específica, moderna y contextual para campañas, mails, landings, benchmarks y piezas comerciales.

---

# 1. Rol de este grupo

Este grupo complementa los 30 iconos base y se activa cuando la pieza necesita representar:

- innovación;
- categorías de consumo más finas;
- entretenimiento más específico;
- canales digitales;
- protección y confianza;
- contextos de uso más concretos.

No reemplaza al sistema base.  
Lo **extiende** cuando un mensaje necesita más precisión.

# 3. Cuándo usar este grupo

Usar estos iconos cuando el mensaje principal sea más específico que los rubros generales del grupo 2 o más contextual que las mecánicas del grupo 3.

Ejemplos:

- si el mensaje dice “beneficios en cine”, usar **33_cine** y no el genérico **20_entretenimiento_musica**;
- si el mensaje dice “app Mi Banco”, usar **40_app_canal_digital** y no **04_wallet_pago_movil**;
- si el mensaje dice “compras protegidas”, usar **39_seguridad_proteccion** y no un icono cualquiera de tarjeta.

---

# 4. Regla de especificidad

Siempre preferir el icono más específico disponible.

```text
Cine → 33_cine

App del banco → 40_app_canal_digital
NO → 04_wallet_pago_movil

Seguridad / protección → 39_seguridad_proteccion
NO → 01_tarjeta_visa
```

# 6. Diferencias críticas

## 6.1 Tecnología vs Inteligencia Artificial

**17_tecnologia**
- hardware;
- electrónica;
- gadgets;
- notebooks;
- smartphones.

**31_inteligencia_artificial**
- IA;
- chatbot;
- automatización inteligente;
- recomendación asistida;
- experiencias AI.

Si la campaña trata de “innovación basada en IA”, usar **31**.  
Si trata de “compras en tecnología”, usar **17**.

---

## 6.2 Pago recurrente vs Streaming / Suscripciones

**23_pago_recurrente**
- mecánica genérica de cobro periódico.

**32_streaming_suscripciones**
- caso concreto de contenido por suscripción / streaming.

Si el mensaje habla de “suscripciones en plataformas de streaming”, usar **32**.  
Si habla de “pagos automáticos mensuales” sin rubro concreto, usar **23**.

# 12. Principio final

Este grupo debe usarse para **agregar precisión**, no para volver más compleja la comunicación.

La pregunta de control debe ser:

```text
¿El mensaje necesita un icono más específico que los 30 base?
```

Si la respuesta es sí, usar el grupo 4.  
Si no, quedarse con la biblioteca base.

El objetivo sigue siendo el mismo:

> **hacer que el cliente o lector entienda el mensaje con rapidez, claridad y consistencia visual.**
