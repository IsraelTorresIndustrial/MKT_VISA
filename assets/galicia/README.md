# Banco Galicia — Carpeta de Activos Oficiales

Esta carpeta está dedicada a centralizar los recursos visuales y piezas de **Banco Galicia**:

## Estructura
- `icons/`: Íconos 3D y vectoriales de medios de pago, rubros y mecánicas de Galicia.
- `logos/`: Logotipos oficiales (versión institucional naranja/blanco, positivo, negativo).
- `creatives/`: Banners hero, cabeceras de email y creatividades de campaña.
- Agrega aquí tus archivos `.png`, `.svg`, `.jpg`, `.webp` o markdowns de directrices según los indiques.
