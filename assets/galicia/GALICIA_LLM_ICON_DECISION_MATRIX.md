## ⚡ 1. DIRECTIVA CRÍTICA PARA LLMs: URLs CDN DE PRODUCCIÓN VERCEL EDGE
> [!IMPORTANT]
> **¿Por qué los LLMs deben usar exclusivamente las URLs canónicas absolutas de Vercel (`https://mkt-visa.vercel.app/assets/galicia/...`)?**
> 1. **Cero Enlaces Rotos**: En campañas de correo electrónico, landing pages o compiladores de diapositivas DOM-to-PPTX, el motor de rendering realiza peticiones HTTP directas al Edge. Las rutas relativas (`assets/...`, `./icons/...`) o locales (`file:///...`) se rompen inmediatamente.
> 2. **Renderizado Retina 2x**: Los headers hero cuentan con un ancho nativo de 1100px. Al insertarse en correos de 550px o 600px con `width="100%"` o `max-width="550px"`, ofrecen máxima nitidez en pantallas de alta densidad (iPhone, iPad, MacBook Retina, displays OLED).
> 3. **Canal Alfa RGBA Transparente**: Los 23 íconos 3D poseen fondos transparentes limpios de 32 bits, adaptándose sobre fondos blancos `#FFFFFF`, crema institucional `#FFFBF7` o contenedores de tarjeta.
> 4. **CORS Permisivo (`*`)**: Habilitado en Vercel Edge para evitar bloqueos cross-origin en clientes de correo y navegadores.

### Estructura de URLs Canónicas
```text

https://mkt-visa.vercel.app/assets/galicia/icons/{filename}.png
```

## 🎯 4. ALGORITMO DE INFERENCIA EN 5 PASOS PARA AGENTES LLM
Cuando recibas un requerimiento de copy o brief para una comunicación de Banco Galicia:
1. **Paso 1: Detectar Tono y Entidades Clave en Voseo Argentino**: Identifica términos como *ahorrá*, *comprá*, *adherí*, *pagá*, *despreocupate*, *disfrutá*, *luz*, *gas*, *seguro*, *recital*, *2x1*, *preventa*.
2. **Paso 2: Aplicar la Jerarquía Semántica**:
   $$\text{Mecánica / Rubro de Consumo} > \text{Alerta de Vencimiento / Pago} > \text{Sponsoreo Oficial Galicia} > \text{Estilo de Header (Foto vs Ilustrado)}$$
3. **Paso 3: Resolver Desambiguaciones**: Revisa si el beneficio es una preventa Galicia oficial (`entradas_2.png`), un vencimiento de factura (`auriculares_2.png`), o un show de stand-up (`microfono_2.png`).
4. **Paso 4: Seleccionar el Header de Cabecera Adecuado**:
   - ¿El email habla de café/rutina diaria? → `header_promos_visa_permanentes_07.png`.
   - ¿Habla de shopping/locales físicos/cuotas? → `header_promos_visa_permanentes_08.png`.
   - ¿Habla de billeteras móviles (MODO, Apple Pay) o Tap to Pay? → `header_promos_visa_permanentes_09.png`.
   - ¿Habla de delivery/ecommerce con grilla inferior? → `header_promos_visa_permanentes_10.png` (compacto).
   - ¿Requiere un estilo sobrio, ilustrado y técnico? → `header_promos_visa_permanentes_11.png` (compacto claro).
   - ¿Es un gran evento comercial (Hot Sale, Cyber Monday)? → `header_promos_visa_permanentes_12.png` (naranja shock).
5. **Paso 5: Emitir URLs Canónicas con Snippet Exacto**: Devolver el código HTML con URL absoluta a `https://mkt-visa.vercel.app/assets/galicia/...`.
